# Local Road Images

Place authorised copies of the original `images/` resources here. These include road arcs, cross and hyperbola modules, start/end markers, cars, and obstacles.

The source uses paths such as:

- `images/arc1.png` through `images/arc8.png`
- `images/cross1.png` and `images/Cross2.png`
- `images/Hyperbola1.png` through `images/Hyperbola4.png`
- `images/start_image.png`, `images/end_image.png`, and `images/end.png`
- `images/roadblock.png`

The original `file:Images/` references were normalised to `file:images/` for case-sensitive filesystems. Original media files are excluded until their third-party sources are documented.
